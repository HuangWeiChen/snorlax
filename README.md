# 💤 Snorlax-iOS-App (卡比獸)

這是一個極度簡約、充滿慵懶氣息的 iOS 應用程式。它的唯一使命，就是在你的螢幕上完美呈現最可愛的「卡比獸」！

## ✨ 專案特色

*   **極致簡約**：沒有複雜的按鈕與功能，打開 App 就能立刻獲得心靈祥和。
*   **新手友善**：非常適合作為 iOS 開發初學者練習 UI 佈局、圖片載入 (Image View) 或 SwiftUI 繪圖的參考專案。
*   **療癒滿分**：看著螢幕上的卡比獸，隨時提醒自己該休息了。

## 🛠 開發環境 (可依你的實際情況修改)

*   **語言**：Swift
*   **框架**：SwiftUI / UIKit (請擇一)
*   **工具**：Xcode 15+ 
*   **支援系統**：iOS 16.0+
